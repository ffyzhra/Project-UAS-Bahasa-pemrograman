# Password Generator (Tkinter)

A desktop password generator built with Python and **Tkinter**, made as the final project (UAS) for the Programming Languages course at Esa Unggul University.

## Features

- Generates a password from the username plus random characters
- Choose which character sets to use: uppercase, lowercase, digits, symbols
- Option to keep your own password instead of a generated one
- Input validation with error dialogs (e.g. empty username)

## Run

```bash
python Project_UAS_Bahasa_Pemrograman.py
```

Needs only the Python standard library (Tkinter ships with Python).
